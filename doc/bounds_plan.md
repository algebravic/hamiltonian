# Plan: `hamiltonian/bounds` and `doc/square_sum_bounds.tex`

## Python package `hamiltonian/bounds/`

All modules use relative imports. Run them from the repo root with
`uv run python -m hamiltonian.bounds.<module>`.

| module | purpose |
|---|---|
| `squares.py` | `issq`; adjacency of G(n); exhaustive and randomized Hamiltonian s–t path search |
| `moves.py` | parity-preserving moves (Def. 3.1): find, verify, choose a maximum separated family |
| `lift.py` | Gerbicz's t²-lift of a path, and of its moves (Lemma 3.3) |
| `glue.py` | glue-arrangement search for given (t, u, w, parity of n); `--exhaustive` proves that none exist for t = 3 |
| `certificate.py` | checks `data/bounds/certificate.json` (seeds n₀ = 45, 35, 43) and the iterated lifts (Theorem 3.5) |
| `seeds.py` | search for seeds with many separated moves |
| `sinkhorn.py` | the constant C ≈ −0.632538 (Schrödinger system) |
| `residuals.py` | log H(n) minus the prediction, using `data/b071983.txt` |
| `edges.py` | e(G(n)) ~ (2/3)(√2−1) n^{3/2}, and the factor 2 on multiples of 4 |

The earlier copies `base.py`, `lift.py` and `verify.py` in `hamiltonian/bounds/` used absolute imports. `lift.py` is replaced. `base.py` and `verify.py` are superseded by `moves.py`, `seeds.py` and `certificate.py`; they are left in place, since deleting files is not enabled.

## Addendum (talk preparation)

- `bregman.py`:
  - computes the exact Bregman–Minc upper bound
    log H(n) ≤ Σ_i log((d_i+1)!)/(d_i+1) + log(n!)/n − log 2, which comes from G(n) plus a universal vertex;
  - computes its asymptotic constant B = √2/2 − (3/2) log(1+√2) ≈ −0.614954, so that log H(n) ≤ (n/2) log n + (B−1)n + o(n).
- `talk_figures.py`: writes the PDF figures for `doc/talk/square_sum_talk.tex` into `doc/talk/figs/`:
  - the adjacency matrix of G(n) in natural order and sorted by residue mod 4;
  - the kernel κ and the Schrödinger potential a(x);
  - normalized log H(n) against the lines C and B;
  - the residual plot.
- Paper: add the upper bound (Proposition 6.1, with C ≤ B by the Gibbs variational principle) and the arithmetic obstruction to pseudo-randomness:
  - the class 1 mod 3 is an independent set of size about n/3;
  - there are no edges between the classes 0 and 2 mod 4.

## Addendum (deterministic route, paper §7 and Appendix A)

- `bethe.py`, for the actual graph G(n):
  - computes the symmetric Sinkhorn scaling S = D A D of the adjacency matrix A of G(n);
  - computes the Bethe free energy F(S) = Σ[−s log s + (1−s) log(1−s)]. By Gurvits–Samorodnitsky this is a rigorous lower bound for log per A, the log of the number of cycle covers;
  - reports (F − (n/2) log n)/n against C − 1;
  - also measures how far the continuum ansatz p_ij = a(i/n) a(j/n)/√n is from doubly stochastic (largest row-sum error), which is the input to Lemma 7.3.
- Paper:
  - new §7, "A deterministic route for G(n)";
  - Appendix A (about 5–6 pages) explaining graph limits, permutons and their large deviations, the Schrödinger problem, Sinkhorn scaling, and the discrete Bethe computation.

## Addendum (Barvinok's Hamiltonian permanent, paper §7.6)

- `hamp_predictor.py`: for each n with exact data, computes the symmetric Sinkhorn scaling S = DAD of A_{G(n)} (dense, 40000 iterations) and the predictor
  Ĥ(n) = (n/2)·(n!/nⁿ)·(∏ d_j)^{−2}·(mean d)²,
  then the residuals log H(n) − log Ĥ(n), next to the residuals of the constant-C formula.
- It also evaluates, for the record, the two first-order "loop" corrections that failed:
  - the pair-collision factor exp(−Σ_ℓ (1−ℓ/n)(tr S^ℓ − 1));
  - the factor det'(I − S).
- It writes `doc/figs/predictor.pdf`, a plot of both residual curves.
- Paper: new subsection 7.6, "Barvinok's identity and a finite-n predictor".
